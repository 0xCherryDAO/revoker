# Revoker

Отзыв разрешений для своих кошельков в Ethereum, Base, Optimism, Arbitrum One, Polygon, BNB Smart Chain и Avalanche C-Chain.

## Запуск

Нужен Python 3.11 или новее. Из папки проекта выполните в PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Добавьте приватные ключи в `data/wallets.txt`, по одному на строку, с префиксом `0x` или без него. Программа подписывает транзакции локально. Файл исключён из Git и недоступен через браузерный интерфейс. Храните его локально.

```powershell
.\.venv\Scripts\python.exe ui.py
```

На вкладке **Главная** выберите сети. Кнопка **Проверить** показывает найденные разрешения без транзакций. **Запустить отзыв** отправляет транзакции. Кнопка **Остановить** завершает работу между порциями поиска или после текущего отзыва. Для оплаты комиссии нужна нативная монета каждой сети. За ходом выполнения можно следить во вкладке **Журнал**.

Те же операции доступны из консоли:

```powershell
.\.venv\Scripts\python.exe main.py --dry-run --network base
.\.venv\Scripts\python.exe main.py
```

Без `--network` обрабатываются все встроенные и добавленные сети. Флаг можно указать несколько раз. Без `--dry-run` консольная команда отправляет транзакции.

## Настройки сетей

Во вкладке **Настройки** выберите встроенную сеть, чтобы заменить её RPC или вернуть адрес по умолчанию. Для своей EVM-сети нажмите **Добавить сеть** и укажите название, Chain ID и URL RPC (`https://` или `http://`). Начальный блок и адрес развёрнутого Permit2 можно указать дополнительно. RPC должен поддерживать исторические запросы `eth_getLogs`. При запуске Revoker сверяет Chain ID по RPC.

Настройки сохраняются в `run/network-settings.json` и используются браузерным интерфейсом и `main.py`. Добавленную сеть можно выбрать на главной или передать в CLI по её идентификатору, например `--network chain_324`. Переменная окружения `REVOKER_RPC_<ID>` имеет приоритет над сохранённым URL.

## Какие разрешения отзываются

- ERC-20. Программа обнуляет текущий allowance, включая разрешения, созданные через опубликованный ERC-2612 `permit`, и разрешения самого контракта Permit2 на расходование токена.
- ERC-721 и ERC-1155. Программа отключает разрешения операторам и снимает индивидуальные аппрувы ERC-721 на токены, которыми кошелёк владеет сейчас.
- Permit2 AllowanceTransfer. Для найденных пар токен–spender с ненулевым лимитом программа сдвигает текущий nonce на единицу и обнуляет лимит.

Подписи `permit`, которые ещё никто не отправил в блокчейн, в истории отсутствуют. Для их отмены нужны данные конкретной подписи или предусмотренный контрактом способ изменения nonce. Отзыв ERC-20 allowance, выданного Permit2, блокирует расходование этого токена через Permit2, пока allowance снова не выдан. Программа находит разрешения, которые оставили стандартные события в доступной истории.

## RPC и история

Проверка и отзыв по умолчанию начинают поиск через RPC. Если запрос логов не удаётся после повторов, программа пробует публичный SQD Portal с первого непрочитанного блока. Для BNB Smart Chain со штатным RPC первым используется SQD Portal. Диапазон в 5 000 блоков потребовал бы десятков тысяч запросов для полной истории. Блоки, которых ещё нет в индексаторе, дочитываются через RPC. При неполном сканировании программа покажет ошибку для этой сети.

При ограничениях RPC диапазон временно уменьшается и снова растёт после успешных запросов. Пройденные финализированные блоки сохраняются в `run/approval-history/`. При повторном запуске с тем же набором кошельков программа сверяет хеш сохранённого блока, дочитывает историю и проверяет актуальное состояние всех найденных разрешений. Если RPC поддерживает финализированные блоки, кеш позволяет продолжить и после остановки. Он содержит публичные адреса и данные событий. Приватные ключи остаются в `data/wallets.txt`.

Встроенные RPC, начальные блоки и размеры диапазонов заданы в `config.py`. Оставьте начальный блок `0`, если нужно проверить всю историю. Параметр `index_first` задаёт приоритет SQD Portal для штатного RPC. Для временного переопределения RPC можно задать `$env:REVOKER_RPC_BASE = 'https://ваш-rpc'` перед запуском. При переопределении история этой сети читается из указанного RPC, если для встроенной сети отдельно не задан `ENVIO_API_TOKEN`.
